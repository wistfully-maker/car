# QR 包现场操作 README 设计

## 目标

将 `qr_item_search/README.md` 重写为可直接用于开发、实车测试和后续模块联调的操作手册。

## 内容边界

- 记录当前已经实现的 QR 连续搜索节点、参数、话题和命令。
- 分别说明“依赖已启动后的一键启动 QR 包”和“底盘、相机、QR 包分步启动”。
- 明确搜索结束不等于节点退出，并给出正常停止、异常停止和关机前清理步骤。
- 明确当前 QR 包不直接订阅 `/task1/pickup_arrived`；未来由 `task1_orchestrator` 将到达事件转换为 `/qr_item_search/start`。
- 给出语音目标、到达事件、QR 结果、LLM 请求/结果、语音播报和后续导航的协议及命令行模拟方法。
- 尚未实现的编排器、LLM、TTS 和导航消费者必须标注为“待开发”，不得描述为当前可运行功能。

## 文档结构

README 按“先运行、再理解、后联调”的顺序编排：快速开始、安全条件、一键/分步运行、开始与停止、话题协议、模拟联调、故障排查、测试与现场清单。
